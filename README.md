# $BULLSHIT landing page

React + Vite. No utility. Just bullshit.

## Run
    npm install
    npm run dev -- --host

## Build
    npm run build

## Configure
- `src/config/site.js`: contract address and buy link (empty = "[CA COMING SOON]", COPY CA disabled)
- `src/config/gallery.js`: add meme images to the multiverse gallery

`node scripts/build-single.mjs` bundles everything into one HTML file (needs esbuild).
